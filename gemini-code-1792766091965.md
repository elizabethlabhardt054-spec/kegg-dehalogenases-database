# kegg-dehalogenases-database

Catalogação de enzimas deshalogenases, consórcios em cocultura e catalisadores/cofatores via KEGG[cite: 1].

## 🧬 Sobre o Projeto
Este repositório armazena dados estruturados e ferramentas em Python para catalogar enzimas envolvidas na biodegradação de compostos organoclorados (como isômeros de HCH), com foco em aplicações de biorremediação em solos tropicais.

## 📁 Estrutura do Repositório
- `dehalogenases_catalog.json`: Base de dados em formato JSON contendo genes, vias metabólicas e enzimas (ex: `linA`, `linB`).
- `parser.py`: Script automatizado para validação e inserção dos dados numa base de dados SQLite local.
